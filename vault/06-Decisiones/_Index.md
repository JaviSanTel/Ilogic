# Decisiones de Arquitectura (ADRs)

## ¿Qué es un ADR?
Un registro breve de una decisión técnica relevante:
qué se decidió, por qué, y qué alternativas se descartaron.

## Template
```
# ADR-XXX — Título

## Estado
Propuesto / Aceptado / Deprecado / Reemplazado por ADR-YYY

## Contexto
Qué problema se estaba resolviendo.

## Decisión
Qué se decidió.

## Alternativas descartadas
- Opción A: descartada porque...
- Opción B: descartada porque...

## Consecuencias
Qué implica esta decisión a futuro.
```

# Frase por Goteo

## Descripción
Las letras de una frase "caen" en columnas mezcladas.
Reordenar las letras dentro de cada columna para reconstruir la frase.

## Mecánica
- Letras en columnas, arrastrables verticalmente
- Las negritas separan palabras (posición fija)
- Victoria: frase reconstruida correctamente
